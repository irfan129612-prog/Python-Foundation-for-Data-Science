# 🐍 Python Foundations for Data Science

A hands-on collection of **10 Python labs** designed to build a strong programming foundation for **Data Science, Data Analytics, Automation, and Python-based applications**.

This repository documents my practical learning journey through Python fundamentals — starting from basic syntax and data types and progressing toward file handling, APIs, error handling, logging, and command-line data processing.

---

## 📌 Repository Overview

Python is one of the most widely used programming languages in Data Science because of its simplicity, flexibility, and powerful ecosystem.

The purpose of this repository is to strengthen the core Python concepts required before moving toward advanced topics such as:

* Data Analysis
* NumPy
* Pandas
* Data Visualization
* Machine Learning
* Data Science Automation
* API Integration
* Data Processing

The repository contains **10 practical labs**, with each lab focusing on an important Python programming concept.

# 🚀 How to Use This Repository

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/Python-Foundations-for-Data-Science.git
```

Navigate to the repository:

```bash
cd Python-Foundations-for-Data-Science
```

Run a Python file:

```bash
python filename.py
```

For some labs, additional Python packages may be required.

Example:

```bash
pip install requests
```
